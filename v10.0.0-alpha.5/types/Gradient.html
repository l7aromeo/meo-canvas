    A gradient, as a fill or as the alpha of a Mask.

    One kind per geometry, and each carries only what it reads: a radial gradient has no direction and a linear one has no centre, so neither can be given a value nothing looks at.

    import type { Gradient } from 'meo-canvas'

    const fade: Gradient = { type: 'linear', direction: 'to-bottom', colors: ['#101014', 'transparent'] }
    const dial: Gradient = { type: 'conic', from: 90, stops: [{ offset: 0, color: '#f0c' }] }
