    Optional ReadonlyrenderLabelItem

    renderLabelItem?: (
        props: { index: number; item: string },
    ) => SceneNode | null | undefined

    Draw the label beside each value yourself.

    The signature is v1's and the contract is not. v1 lays the returned node out detached during painting and draws it at a position derived from its measured size. Here the node is placed — centred on the same point by ordinary layout — so it participates in the scene rather than being measured and discarded.
