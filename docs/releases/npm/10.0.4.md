### Fixed

- **An animated AVIF is read in the colour its container states.** A still
  image carries its colour description among its item properties; an animation
  carries it inside the sample entry in `stsd`, three levels further down, and
  nothing descended that far — so such a file was decoded by its bitstream
  instead, and an encoder that describes colour in the container while leaving
  the sequence header unspecified produced an image in the default space with
  nothing reported. Precedence is now shared with the still path, and the
  colour is read per track, because an animation with transparency has two and
  the alpha track's description is not the picture's.

  This arrives with `meo-skia-canvas` 0.16.3 and is that project's
  measurement rather than one taken here.

**Nothing else in this release reaches this surface.** The rest of it is four
chart fixes on the Rust crate, and every one of them is a case where the crate
disagreed with **this** surface and has been changed to match it. A chart built
here is expanded in JavaScript before anything crosses into the renderer, so
its geometry, its labels and its colours were already what this release makes
the crate produce. The crate's release notes describe them.
