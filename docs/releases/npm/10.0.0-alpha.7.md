### Fixed

- A percentage height on an out-of-flow box resolved against the flex parent
  rather than the containing block, and came out at zero. An absolutely
  positioned box's containing block is the padding box of the nearest positioned
  ancestor; a fixed box's is the viewport, or a transformed ancestor. The box
  does not contribute to that height, so it is settled before the box is laid
  out and there was nothing circular to refuse.

  The report was about `position: absolute`, and **`position: fixed` was broken
  the same way** — including where the containing block is the page itself.
  A box sized by opposing `top` and `bottom` insets now gives its children a
  height to resolve against, where before a `height: '100%'` child came out at
  zero.

  Measured against Chrome across fifteen cases before anything changed, with the
  four rows that had to stay put — an in-flow percentage against a content-sized
  parent among them — holding throughout. (#84)

- An outset `boxShadow` vanished on any node with `overflow` other than
  `'visible'`. `overflow` clips an element's content and descendants; an outset
  shadow is painted outside the border box and is not content, so the element's
  own overflow does not touch it. Inset shadows are drawn inside and are still
  clipped, which is correct and unchanged.

  `'hidden'`, `'scroll'` and `'auto'` were all affected, and all now draw the
  shadow as Chrome does. (#83)
