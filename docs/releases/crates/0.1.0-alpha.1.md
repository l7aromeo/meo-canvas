The first release of the Rust surface. Four crates publish together at this
version: `meo-canvas-scene`, `meo-canvas-core`, `meo-canvas` and
`meo-canvas-cli`.

It is a prerelease, so `cargo add meo-canvas` will not resolve it. Ask by name:

```toml
meo-canvas = "0.1.0-alpha.1"
```

The npm package and this crate carry their own version numbers and are not
comparable; they are two surfaces over one core rather than two builds of one
release.

### Added

- `meo-canvas` — the authoring surface. Build a tree of boxes, rows, columns,
  grids, text, images and paths, hand it to a `Renderer`, and get back encoded
  bytes. Layout is flexbox and CSS grid through taffy; drawing is Skia; text is
  shaped and broken to match what a browser does rather than what a canvas does.
- Encoding to png, jpeg, webp, avif, tiff, bmp, ico, svg, pdf, gif, apng and
  raw. Rendering and encoding are separate calls on a retained canvas, so two
  formats of one picture cost one resolve, one measure, one layout, one paint
  and two encodes.
- A scene carries one or more pages, which become frames in gif and apng, sheets
  in pdf and tiff, and sizes in ico. Pages are trees the caller has already
  built, so an animation needs no clock and the renderer never calls back into
  caller code mid-render.
- `Scene::content_height` makes a page as tall as its content, with `size.height`
  becoming a floor rather than the height.
- An image source can carry its own HTTP headers, and `Scene.http` sets them
  once for a whole scene; a source's own headers merge over it per header name.
- `meo-canvas-scene` — the scene types and a hand-written byte codec, with no
  dependency on Skia, on the layout engine or on a serialization framework. The
  byte layout is a specification another language can target, and errors name
  the byte offset.
- `meo-canvas-cli` — renders a scene file or a pipe.
- Optional features, none of them on by default: `net` fetches an
  `ImageSource::Url`, and a GPU backend named for the platform that has one,
  `metal` on Apple targets and `vulkan` elsewhere. A build naming none renders
  on the CPU and links no HTTP stack, and a URL is then
  `Error::UnresolvedSource` — a message that names the feature. Nothing in the
  core requires an async runtime.
