Both fixes are in `meo-canvas-core`, so they reach the Rust surface and the Node
addon alike.

### Fixed

- A percentage height on an out-of-flow box resolved against the flex parent
  rather than the containing block, and came out at zero. For an absolutely
  positioned box the containing block is the padding box of the nearest
  positioned ancestor; for a fixed box it is the viewport, or a transformed
  ancestor. The box does not contribute to that height, so it is settled before
  the box is laid out and there was nothing circular to refuse.

  `PositionType::Fixed` was affected as well as `Absolute`, including where the
  containing block is the page. A box sized by opposing `top` and `bottom`
  insets now gives its children a definite height to resolve against.

  Measured against Chrome across fifteen cases before anything changed; the four
  controls that had to stay put, including a `min-height` percentage on an
  in-flow child of a content-sized absolute box, hold throughout.

- An outset box shadow was erased on any node whose `overflow` is not
  `Overflow::Visible`. The node's own clip was established before its own box
  was painted, so a shadow drawn outside the border box was clipped away. Inset
  shadows establish their own clip and were always correct.
